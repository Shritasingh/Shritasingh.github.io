Projects

Selected technical projects spanning satellites, optimal control, and modeling.

Advitiy Nano-Satellite

Student Satellite Team, Attitude Determination & Control · IIT Bombay · 2018–2019

Built a modular simulation framework for satellite dynamics and environment for controller testing, validated a PID controller via on-board in-loop simulation on Arduino, and modeled orbital solar power for the CubeSat's electrical budget.

Optimal Control of a Plug-in Hybrid Vehicle

Prof. Ravi N. Banavar, IIT Bombay · 2019

Formulated an optimal control problem minimizing fuel consumption for a given position/speed profile, built a modular closed-loop Simulink simulator across driving cycles and road grades, and solved the OCP via multiple shooting and Pontryagin's Maximum Principle.

Data-Driven Dynamic Modelling Algorithms

Process Systems Engineering · IIT Bombay

Developed discrete-time black-box models using stochastic processes and parameter estimation via optimization; implemented recursive parameter updates for ARX, OE, and ARMAX models, and extended them to block-data updates of parameters and covariance.

Model Predictive Control of a Reactor System

Process Control · IIT Bombay

Designed and simulated an MPC for a nonlinear CSTR to track concentration and temperature setpoints under input constraints, with state estimation and innovation-bias correction for model–plant mismatch.
